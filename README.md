
# LingoWay – User Registration Page

A responsive user registration project built with HTML5, CSS3, and JavaScript.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure

- `register.html` – User registration page (Create Your Account).
- `success.html` – Registration success confirmation page, including a Return to Login button.
- `login.html` – Demo login page designed to simulate the user journey.
- `css/style.css` – Contains all styling, colors, and responsive design.
- `js/register.js` – Handles form validation, including name, email, password, password confirmation, and terms agreement.
- `js/success.js` – Displays the user's name on the success page.
- `js/login.js` – Handles demo interactions on the login page.

## How to Run

1. Extract the project ZIP file if necessary.
2. Open the `lingoway` project folder.
3. Open `register.html` in any modern web browser.

## Password Requirements

Weak passwords are not accepted. The password must:
- Be at least 8 characters long.
- Contain at least one uppercase letter.
- Include at least one special character (e.g., @ or $).

## Notes

- This is a frontend demonstration project.
- It does not include a backend or database.
- The login page is for demonstration purposes only.
